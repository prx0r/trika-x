## 3. Why (root causes, not blame)

1. **No bundle importer exists.** Nothing in svread/tools builds reader
   bundles; `emit_sanskrit.py` vendors lessons, not layers. Bundles arrived
   by hand-copy at some point (Nov 3?) and rotted. There is no scheduled
   sync, no freshness gate, no owner.
2. **Branches diverged.** MVV's gold is on a branch this box doesn't have
   checked out; TW's working branch is 1-behind-and-diverged from its own
   master. You cannot sync from a forked upstream — first reconcile, then
   automate.
3. **Lanes move, surface doesn't follow.** Campaign rebuilt layers in place;
   no event, note, or hook tells svread "re-emit bundles." The chain
   openpatala→translation→trika→svread carries bytes for traces, but reader
   bundles travel by hand.
4. **Silent withholding.** 777 pages withhold L2 correctly (fail-closed ✓),
   but nothing aggregates the miss list, so nobody feels its size. This audit
   is the first count.

## 4. Proposal (ordered, lane-clean)

1. **Reconcile branches first** (lanes): merge or rebase TW box/master,
   decide where MVV lives. No automation before one upstream.
2. **`tools/emit_bundles.py` (svread, read-only):** TW
   `*/data/*.l2.json + passages.jsonl` (+ ipvv lane export when it exists)
   → `data/<work>.json` (existing schema), deterministic, --check, fail
   closed (missing layer → withhold entry, never invent). Reads lanes;
   writes only svread. Needs lane agreement on schema + chunk-id join
   (verse `-v01` vs passage `-p01` forms both occur).
3. **Freshness gate (seo_check G11):** every trace work with a TW ledger L2
   must have a covering site bundle, else listed as known-missing. Makes
   the next rot visible the day it happens.
4. **Backfill order:** ipvv export (crown first) → TAL campaign golds →
   MVV (post-merge) → vbt → tantrasara ahnikas → tail.
5. **Human-gate board with names/dates** for the lane decisions this needs
   (schema sign-off, ipvv export format, MVV merge).

40 missing-but-traceable bundles from byte-verified pack bytes (verify by

hashed excerpt, else withheld with reason; UNKNOWN gates fail closed to
BLOCKED and say so; never overwrites lane-authored bundles). No lane files
touched, no bundles hand-edited. Result live: site went 67 → **107
bundles**, 50 → **90 readable** (`llms.txt` derived), manifest 10,897 →
