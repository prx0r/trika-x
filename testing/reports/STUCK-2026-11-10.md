## 1. The stuck list (ranked by blast radius)

**S1. Human gates don't move; the stockpile grows.**
P-TK1 / ti-ca / rater-2, NGMPP witnesses, Zenodo token, dīkṣā policy — open
since 11-06, zero movement visible. Meanwhile machine-proposed output piles
up: 78 gold works, MVV +3, TAL campaign running, 6 PARTIAL essays, 7 review
packets queued. The architecture's load-bearing assumption is "human
disposes" — but no human is disposing. A verifier with no verifier of last
resort is a warehouse, not a pipeline.

**S2. Owner-action queue (8+ items, none clearable from the box).**
Disk reclaim (96%, needs eyes), cron install, token rotation, Search Console
+ outreach + IndexNow, journey/ledger/trajectory/vis-mode go, audio-render
go, recipe go-aheads, dīkṣā calls. Disk alone blocks tau scale, Mutate
remainder, COMET, R2 work. Everything behind these items is parked, and the
parked list grows faster than the cleared list (which is empty).

**S3. Branch sprawl / parallel realities.**
translation-work `box/decision-trail` vs `origin/master` diverged both ways;
ipvv `box/two-sources-v2` ahead of master; today's untracked
`chunk-verse-*-2026-11-10` bridge files from an unidentified agent; trika-x
main vs peer-review-batch history. No visible merge discipline. Two agents
can currently ship contradictory truths and both be "green" on their own
branch.

**S4. Lane boundary vs red gate.**
translation-work `check.py` is RED (20 proof-harness FAILS) from a 1-line
stdout-trailer bug (`proof_record.py:410` → stderr). We held the read-only
rule and filed it. But: lanes aren't reviewing either (S1). If read-only +
specs produces no lane response in 4+ days, the rule is a polite fiction
while quality drifts on both sides of the fence.

**S5. GEO sequencing may be backwards.**
We built S01–S10 before the S09 baseline, and our own research says GEO
can't create retrieval — only Search Console + inbound links (both
owner-gated, both undone) move `site: = 0`. Without a baseline no tactic
claim is licensed (our standard, not theirs). The build is principled but
unmeasured: by our own rule ("or it is astrology") we cannot yet say it
mattered.

**S6. Doc sprawl.**
DEV-PLAN/MASTER (08-17, stale counts/paths), ROADMAP R4 (stale vs wired
footer), REGISTRY (78 gold) vs todoregistry snapshot (53 gold), amendment
numbers (153 vs 157), VISION-ARCHITECTURE (self-marked historical proposal),
FINAL-TASK peer review (0.5.2 verdict vs current claims). DOCS.md maps the
canonical set, but stale docs aren't bannered consistently. A new agent
quoting the wrong doc will state false numbers with full confidence.

**S7. Witnesses: forever-BLOCKED?**
0 corpus-wide; the only path is NGMPP/manuscript eyes (owner/scholar). No
name, no date, no trip. If there is no actual plan, strategy should admit
permanent UNPINNED and design the authority claim around it instead of
carrying a rung that can never close.

**S8. Formal velocity vs promotion.**
16/154 chunks (10%), 0 Core. Gap-list order exists, but every rung's value
is gated on scholar promotion that never arrives (S1). Question nobody has
answered: is >50% coverage a real target, or should effort redirect to
second-encoder review of the existing 157 before minting new theorems?
