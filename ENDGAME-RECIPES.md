# ENDGAME RECIPES — diary → teachings → media → journey (spec, 2026-11-06)

Owner vision verbatim: `/root/AGENTS.md` §ENDGAME VISION. This doc specs
the recipes. All spec, no builds; lanes dispose. Standing invariants
(non-negotiable): diary is PRIVATE (consent per use, revocable, no
auto-publish of personal material ever); every sourced claim resolves or
it doesn't ship; machine proposes, human disposes; tiers on everything.

## R1 — Diary → personal essay (read)

diary entries (consent) → teacher retrieve-first → essay_compile (diary
voice verbatim + banked claims + tiers) → L3/L4 → audit/pushback →
review → signed text. Owner: nibbanahelp (diary) + essay pipeline.

## R2 — Essay → teaching audio (listen)

Signed essay → audio render (TTS/pack with receipts; existing audio
lanes: R2 svread-audio, aoc patterns — reuse, don't rebuild). Gate:
audio matches signed text (no improvised lines); human listens once.

## R3 — Essay → video (own/publish)

Knowledge dossier (aim + textual orientation + visual rules — R2 essay
renders precedent) → factory render → sealed mp4 (GOLDEN-style gates) →
owner holds the file + publishes at will. Owner: factory lanes.

## R4 — Journey-linked publishing

Video/essay ↔ journey ledger entries (JOURNEY-NOTE spec, owner-gated).
Links are explicit references (journey:<id>), never embeds of private
entries. Journey go still owed.

## R5 — Parables / C2 registers (roadman et al.)

Register renders (genz/roadman/plain) OVER compiled claims (never instead
of them): prompt + model/date + paragraph→claim maps (C2 contract).
Owner lanes hold voice direction. Existing C2 stays; new renders need
lane review (C2 waived in translation lane — books/videos decide their own).

## R6 — Kids books (highest bar)

Compiled claims → simplified register → human reads EVERY line aloud →
age-appropriate review → book pipeline. No invented content, no generated
morals, no unreviewed simplifications. The bar is higher than Scholar:
children can't check our work.

## R7 — Diary book: year review of hardships

Diary year (consent, scoped) → tension arcs (open→loosening→resolved,
human-flipped only) → book pipeline (TEXT-GATE per entry) → publish.
Year boundary explicit; unresolved tensions stay unresolved in print
(honest endings only).

## R8 — Poem book from your words

Diary lines → verbatim selection (arrangement is the only craft; no
generated lines, no paraphrase, compiler law) → L3/L4 craft passes →
book. Your words or nothing.

## R9 — Short movies (NOT YET)

Gated on model quality (bar set by owner when proposed; current models
do not qualify — no build, no tests, no placeholders). On qualification:
packs → render → sealed mp4, same gates as R3. Recorded here so the
recipe exists when the models do.

## Recipe pattern (what makes these one system)

Private source (consent) → compile (verbatim + claims) → sharpen (L3/L4)
→ verify (audit/pushback) → human gates (review/sign) → render (audio/
video/book) → link (journey/bibliography). Same shape, nine flavors.
