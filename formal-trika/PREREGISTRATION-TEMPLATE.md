# PREREGISTRATION TEMPLATE — copy for every new rung (traps mandatory)

**Status:** DRAFT | ACTIVE | PAUSED | SUPERSEDED (one only).

## T-tier ground (or NONE, stated plainly)

Ledger passages, volume spans, VERIFIED-QUOTE entries, record status,
mapping status. Machine-proposed translations are R-ground, never T.

## Formal claim (named theorems, finite scope, method)

One theorem per falsifiable facet. State the model, the scope, and what is
NOT formalized (generative relations, semantics, doctrine — name them).
Every theorem gets a `Covers:` line (which PART of the source it covers,
Axiom-style partial notation — never weaken the source to make it provable;
if the source is wrong, say so).

## Traps (mandatory — the transmission-brief section)

Terms that look alike but differ; flattening risks (membership vs
begetting, counts vs structure); numerology temptations; nearby-but-wrong
targets; unformalizable remainders (recorded, never forced).

## Twins (one refusal each — must_fail exactly-one rule)

Per theorem: the surgical mutant and why unrelated theorems still pass.
Law-coupled claims must be redesigned into separable facets first (F1);
bounds checked for escape (F2).

## Kill conditions (remodel-ready)

What evidence remodels the rung (argmap revision, span wiring, fork
resolution). Never patch a killed rung.

## Tiers

R default; T only with verbatim-bound spans + reviewed translation +
assessor sign. Cited downstream only with this prereg linked.
