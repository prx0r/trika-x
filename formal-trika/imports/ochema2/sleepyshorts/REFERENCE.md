# SLEEPSHORTS REFERENCE — What Ochema Values, and How to Weight Short Selection

**Purpose:** the value system for the longform-audio → high-signal-cut → shorts flow.
Read before selecting or cutting any talk. This is the user's taste, made explicit and
weightable. Grounded in: `ochema2/README.md` (the charter), `ochema2ref.md` (the
inventory), `essays/ESSAYREF.md`, `clean/.opencode/skills/tantraloka-film/SKILL.md`,
`blog/hermes/skills/shorts-from-essay/SKILL.md`, the two worked exemplars
(`sleepyshorts/` — levin, andres-substrate-neutral).

## 0. THE PRODUCT LINE (four rungs, one source)

```
raw lecture  →  high-signal cut(s) (the "sleepy" longform — 30–60 min each)
             →  shorts (the gems, 45s–4min each)
             →  COMPILATION (the highlights reel — all gems stitched in shelf
                order, ~0.5s breathe-gap between them)
```

**A sleepy is a 30–60 min unit.** A 45-min focused talk → one sleepy. A 4-hour
workshop → **multiple sleepies**, segmented at coherent seams (per speaker, per
theme, per session half). Each sleepy must be internally coherent — its own
open/close — because it is a listenable product on its own. Gems are selected
per sleepy; a compilation can be per-sleepy or a cross-sleepy mega-reel.

The compilation is not a new edit — it is the gems in their argument-arc order,
which already reads as the talk's spine in miniature. It works precisely because
the gems were selected as a coherent shelf, not random clips. Build it from the
`gems/` folder, never from a re-cut of the raw talk.

## 1. THE MORAL (what the whole channel is explaining)

**Consciousness — explained with frontier mathematics and science, heard against the
Tantrāloka and the Sanskrit and Greek traditions.**

The one problem, from the frontier: *why does one organized process constitute one
manifest, valenced perspective?* The equation:

```
Dᵢ = Λₚ(M, Πᵢ, Σᵢ)
```

- **M** — manifestness (the Sanskrit summit: prakāśa, recognition)
- **Πᵢ** — participant-specific structure (the Greek summit: Proclus, Iamblichus, participation)
- **Σᵢ** — concrete biological realization (the scientific summit: Levin, QRI, predictive processing, IIT)
- **Λₚ** — the connecting law, **still unknown**

Every talk we process should be scored on: **which summit(s) does it actually move?**
A window that touches two or three summits is automatically more valuable than one
that touches none.

**The discipline (binding, from the charter):** established / interpretive /
speculative — label which. No shared vocabulary counts as convergence without a
shared constraint or prediction. The nine-operation grid is the mapping vocabulary
(manifestation, retention, determination, stream integration, counterfactual
generation, value weighting, finite possibility space, cross-stream boundary,
inter-stream influence).

## 2. TALK TYPES → CUT STRATEGIES (the flow varies by type)

| Type | Example | Scaffolding to cut | Expected cut size |
|---|---|---|---|
| **Structured lecture** | levin "Mind of the Body" | greeting, tangents (Descartes aside), closing, slide-pointing | 10–15% — real cuts |
| **Dense stream-lecture** | andres "Substrate-Neutral" | sensory demo, visual-referencing asides, outro | 5–10% — near all-keep |
| **Conversational / interview** | andres "Talking with Ivan", solms/levin convos | interjections, false starts, chat-reading, partner's filler | variable — quote-level cuts, stitching |
| **Course series** | bettina baumer (pratyabhijñā, shiva sutras) | session housekeeping, recaps of prior sessions, "we'll continue next time" | 10–20% |
| **Workshop / multi-speaker** | TSC 2025 "Is Consciousness Fundamental?" | chair intro, mic-handling noise, break dead air, moderator transitions | 5–10% — the sculpture IS the segmentation |

**WORKSHOP (super-long) → MULTIPLE SLEEPIES (30–60 min each)**, segmented at
coherent seams (per speaker, per theme, per session half). Each sleepy is a
listenable product on its own. Gems are spotted in the SAME PASS as the block
map — read once, extract both. The panel/Q&A segment of a workshop is the gem
motherlode (conversational density); the solo talks yield 1-3 gems each.

**KEY JUDGEMENT — "no cut" is a valid verdict.** If a talk is already dense, the
signal density IS the product. Do not manufacture cuts. This is why long, dense
lectures are the best raw material: the sculpture work is mostly done by the speaker.

**Focused topic = keep it all.** If a talk stays on one focused topic, ship the
high-signal edition whole — no forced splitting, no invented structure. Splitting
into parts is only for genuinely bifocal or loose talks (two distinct halves), and
it serves listening, not signal.

**Andrés is the reference speaker for this flow** — the best talker on the
material. Expect near-all-keep verdicts from him and treat them as praise of the
source, not failure of the flow.

## 3. WHAT COUNTS AS SIGNAL (weight toward these)

Score candidate windows on this list. A window that hits several = a strong short.

**+DEEP (highest weight)**
- A **complete derivation**: the window takes a claim from naive to precise and
  lands the punchline *inside* the window. Setup + payoff in one piece.
- **Summit-crossing**: connects science ↔ Sanskrit ↔ Greek (e.g. valence ↔ rasa ↔
  camatkāra; bioelectricity ↔ prāṇa ↔ luminous body; topology ↔ subtle body).
- **The two identity hypotheses**: intrinsic biological significance = felt valence;
  objective causal closure = phenomenal co-presence.
- **Mapping in action**: a tradition claim mapped onto the nine operations (e.g.
  kañcukas = finite possibility space = embodiment constraints).
- **Counterintuitive, well-argued** claims ("cancer cells aren't more selfish, their
  self got smaller"; "reality is not made of ones and zeros").

**+QUICK (lower weight, allowed as appetizers)**
- Sensory/personal moments (the perfume flower), fun facts (thalamus vs cortex),
  mystery teases ("a devious sleight of hand... and you fell for it").

**−PENALIZE**
- Tease without payoff (the reveal must be in the same or adjacent window — prefer
  stitching tease+reveal into one 2–4 min piece).
- Audio-hostile content (slide-pointing, "as you can see", chat-reading).
- Duplication of another short on the shelf — no repeats.
- Repetition of a point already made better elsewhere in the talk.
- Dead air, false starts, "um" runs — polish with cuts only when the signal survives.

## 4. SHORT SELECTION RULES (the weightings that matter)

0. **Target: 5–10 shorts per hour** (informed judgment, quality over quantity).
   The number is decided by value, not math: a 45-min talk yields 4–7; a 2-hour
   talk 10–15. Every inclusion must add value to the ochema problem — if a
   candidate is a fragment without new wisdom, it doesn't make the shelf just
   because the cap allows it.
0a. **CENTRAL-CLAIM COVERAGE (non-negotiable):** every shelf must include the
   talk's thesis itself — a gem that states the central claim, not just the
   sub-arguments inside its frame. A talk "about substrate independence" gets a
   substrate-independence gem first, then the argument gems. The thesis gem
   usually comes from the talk's opening frame (the claim + the contrarian
   position). Check the shelf against the talk title before finalizing.
1. **A short is a gem of wisdom, not a viral hook.** Select for the highest-value
   moments of the talk: where the speaker is densest and clearest on the central
   problem. Literal nuggets — an argument, an insight, a distinction that, once
   heard, changes how you hear the rest. Never select for virality.
2. **Depth beats brevity.** A 2–4 minute short of someone *explaining why* a thing is
   true beats a random 1-minute clip. Derivation windows get the long form (up to
   4 min); single insights get 45–90s.
3. **One hook, one completed argument per short.** If a window needs setup from
   outside itself, extend it (stitch tease + reveal, setup + payoff) or drop it.
4. **Every short must be a leaf from the high-signal cut** — auditable back to the
   cleaned branch, never a random grab from the raw talk.
5. **Prefer the block over the fragment for lectures** — the natural lecture blocks
   are usually the right windows; for conversational material, stitch the speaker's
   strongest statements on one thread into one piece.
6. **Shelf order mirrors the talk's argument arc** — the gems should read as the
   talk's spine in miniature, not as unrelated clips.
7. **Audit every short** against self-containment (the `short_audit.csv` verdicts:
   OK / PARTIAL / WEAK — flag, extend, or drop).

## 5. WEIGHTING CHEAT-SHEET (scoring a candidate window)

```
+3  complete derivation, punchline lands in-window
+3  crosses summit boundaries (science ↔ Sanskrit ↔ Greek)
+2  maps to a nine-operation cell
+2  counterintuitive claim, argued
+2  quotes the tradition precisely (IAST terms, actual doctrine)
+1  sensory/personal/fun-fact moment
−2  tease without payoff
−2  audio-hostile / visual-referencing
−2  duplicates another short's claim
−1  dead air / false starts
```
Window score ≥ 5 → strong short. 3–5 → usable. < 3 → skip unless it's the only
leaf for a structural block.

> **Note:** "order of value for reach" rankings in the older plan files are
> superseded. Selection is by wisdom density against the ochema problem, at
> ~5 shorts per hour — never by viral potential.

## 8. THE SHORT SPEC (mandatory per short, written at cut time)

Every short gets a spec card before the audio is cut — the title IS part of the
cut decision. If you cannot write a strong spec, the window isn't a gem.

```
### G<n> — <working name>
**Title (YouTube):** <the real title — 5-7 words, declarative, precise not clickbait>
**Parent:** <talk-slug> · sleepyN (the sleepy it came from — always labeled)
**Why gold:** <the wisdom: what changes in the listener once this is heard;
               the highest-value moment it captures; how dense it is>
**Standalone:** <does the audio make sense alone, cold? setup+payoff in-window?
               YES / PARTIAL (why) / NO — flag what context it needs>
**Ochema alignment:** <which summit(s) it moves (M / Πᵢ / Σᵢ / Λₚ); which of the
               nine operations it maps to; which tradition bridge it makes>
```

Gem audio files also carry the parent in the ID3 comment tag (`ffmpeg -metadata
comment="parent=<talk-slug>:sleepyN"` at cut time) so the chain survives any
re-organization of the folder.

### Title rules (calibrated from the blog dataset: 94 channels, 14,030 videos)

| Rule | Evidence |
|------|----------|
| **5-7 words** | breakout titles avg 7-10.75 words; full-model says <7 (negative beyond) |
| **No numbers** | #1 negative predictor (-32% ESOTERICA, -9% across dataset) |
| **No colons** | -10.5% Asangoham; negative in the YouTube headline engine |
| **No exclamation marks** | rarely used, rarely breakout |
| **Declarative "The [X] Of [Y]"** | Asangoham's winning formula ("The Dark & Divine Side Of Kundalini Yoga", 7w) |
| **Questions = risky for small channels** | +34% at 1M+ subs, only 5% breakout at 355k; "Why"/"What" only when the channel is established |
| **No wordy qualifiers** | "actually / really / hidden-in-every / literally" are word budget, not signal |

If the title needs more than 7 words, the window is too broad — narrow the claim.

Keep all four fields in `GEMS.md` per talk. `PARTIAL`/`NO` standalone verdicts
mean: extend the window, stitch, or drop — never ship with a shrug.
