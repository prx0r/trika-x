# MAPS

The standardised mapping of every tradition's claims onto the
nine-operation grid (plus ground / transformation / practice).
Three sub-directories:

- `terms/` — the grid itself, one file per operation, with the
  textual anchors (ĪPK 1.3.7 etc.) and the scientific counterparts
  (mapping only, never identity)
- `traditions/` — each tradition's claims mapped onto the grid
- `science/` — the alignment check: which mapped claims are
  accommodated / contradicted / silently open

Rule: same grid cell = correspondence (C). No merging of
vocabularies. No convergence without a shared constraint or
prediction.
