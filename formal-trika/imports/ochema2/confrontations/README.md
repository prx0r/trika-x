# CONFRONTATIONS

The record of what each theory or text claims, graded against the
corpus. The existing confrontation records (from the ochema project)
are kept as-is — they are the record of the theories' actual claims,
and they are not wasted. New confrontations follow the METHOD claim-
file format.

Existing records: the-occhema-object/confrontations/ (20+ records:
IIT, Orch-OR, Friston, Levin, Doyle, Gowan, Walter Russell,
Atmanspacher, Polkinghorne, the peer-review itself).
