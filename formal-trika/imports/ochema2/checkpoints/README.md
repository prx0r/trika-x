# CHECKPOINTS

A checkpoint is a compact, source-grounded record of conclusions that
survived scrutiny and now constrain later work. Checkpoints are
append-only in effect: new checkpoints supersede but do not delete
old ones; the history of the enquiry is preserved.

## The ochema2 checkpoints (to be written)

```
# CHECKPOINT NN

SURVIVES: <what survived, with statuses>
SUPERSEDES: <what it replaces>
CONSTRAINS: <what later work must respect>
```

## The correction discipline

- A correction is an advance, not a failure — logged, dated, versioned.
- A dead-end is a result: it narrows the search space permanently.
- No checkpoint is deleted. The record of the error is part of the
  record.
