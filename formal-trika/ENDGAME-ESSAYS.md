# ENDGAME ESSAYS — reconciliation: schemas × translation × cruxes × scholar

The batch endgame: a huge run of interesting essays, agent-compiled as
formal publications, peer-reviewed, published, video-rendered. How the
four systems compose (each keeps its schema; joins are explicit):

```
translation-work (T1/L0/argmap/L2/C1 + volumes + records)
  │ passages.jsonl locators + immutable_ids + layer_sha256
  ▼
trika-x formal (theorems + twins + EVIDENCE + tiers + spans)
  │ file :: theorem keys + chunk locators + tier notes
  ▼
crux queue + treeka (882 uncertainties + 909 keyed passages + gaps)
  │ crux id + locator + question text
  ▼
essay_compile (voice verbatim + frozen claims + tiers + markers + graph)
  │ expansion draft + receipt + graph nodes/edges
  ▼
v6 prose (pattern passes, quotes untouched)
  ▼
svread audit/pushback (markers resolve, quotes bind, destroy ×2)
  ▼
Scholar review → sign → branch → DOI → bibliography
  ▼
video packs (knowledge dossier: aim + orientation + visual rules)
```

## Join keys (the reconciliation, stated once)

- Chunk locator (`tsa08-p04`) joins ledger ↔ argmap ↔ EVIDENCE ↔ treeka
  ↔ essay markers ↔ lingua `chunk:` IDs.
- Immutable IDs (`pt:pid:…`) join snapshot ↔ bridge (byte identity).
- Theorem keys (`File :: name`) join Lean ↔ EVIDENCE ↔ treeka formal
  column ↔ essay formal notes (↔ future lingua `theorem:` IDs).
- Essay IDs (`essay:<sha>`) join drafts ↔ reviews ↔ branches ↔ DOI
  bundles ↔ bibliography ours-entries.
- Corpus unit IDs (`source:uid`) join essay-corpus ↔ compiled voice.
- Openpatala work IDs join dossiers ↔ records ↔ lingua ↔ submissions.

## Batch order (autonomous agent loop)

crux queue ranked → compile per crux (voice + frozen claims) → v6 →
audit → pushback → receipts → review queue (human) → sign → DOI →
video pack. Hermes skills per stage on activation. Priority: finished
ground first (22 tsa + 14 TAL golds), speculative topics second,
channeling program third (āpta-test framing).

## What reconciles what (no double systems)

- Schemas: each lane native; joins by keys above, never merged.
- Translation: read-only source of grounds (their lane).
- Cruxes: queue is the batch backlog (ours).
- Scholar: review + publish authority (their lane + humans).
- Videos: dossier-shaped packs (factory lanes).
