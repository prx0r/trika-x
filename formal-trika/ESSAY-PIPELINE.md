# ESSAY PIPELINE — unified stages (translation-work discipline for essays)

Unites workengestation (v6 prose passes, typed essays, link graph),
trika-x essay_compile (voice + banked claims), svread audit/pushback,
Scholar review/publish. Each stage: gate that marks it done + owner.
Machine proposes throughout; human disposes. Runner: Hermes skills +
cron (installed on box; activation = owner call).

## Stages

| # | Stage | Does | Gate | Owner |
|---|---|---|---|---|
| 0 | Source | pin passages/argmaps/voice/research objects (hashes) | all inputs pinned + licensed | assessor |
| 1 | Compile | voice verbatim + banked claims + tiers + markers + graph | essay_compile receipt (quotes count, units count, CITED ratio) | compiler (agent) |
| 2 | Prose | v6 passes (Write→Identify→Repair→Texture, 9 patterns, smuggle tests) | pattern scan clean; no rewrite of quotes (compiler law) | writer (agent) + assessor spot-read |
| 3 | Audit | link_claims + audit_draft (markers resolve, quotes bind) | 0 fails; warns triaged or recorded | svread harness (auto) |
| 4 | Pushback | interpretive destroy ×2 families | objections answered or kept-open honestly | models + assessor |
| 5 | Review | request → annotations → decision → revise | human decision recorded | scholar reviewer |
| 6 | Publish | signoff → branch → DOI → bibliography listing | 409-clean signoff; token-gated DOI | author + owner token |

Fail-closed everywhere: a stage that fails blocks downstream (never
degrades). Drafts without markers fail stage 1. Unreviewed drafts never
reach stage 5. Unsigned essays never reach 6.

## Channeling focus program (āpta-test framing)

Queue (each through CHANNELING-SABDA-NOTE rule: quote-T, content-H,
never grounds): Seth density/synthesis objects → Cassiopaean transcripts
(locate full text; assessment cites, files pending) → subtle-body shelf
(density-subtlebody/*, Steiner, Montalk) → Law-of-One comparisons
(8 topics filed). Output per item: assessed claims table + essay topic +
graph nodes. Assessors: assessor batches; scholar disposes.

## Hermes mapping (on activation)

One skill per stage (compile/prose/audit/pushback chores), cron nightly
verify + arrivals, sessions per essay (receipts filed), kanban for the
review queue. Memory: prompts shas + decisions (never prose bodies).
No auto-promote, no auto-publish, no auto-sign — enforced in skill text.
