# TIERS — the six grades, one language (adopted 2026-11-06)

Quoted from the research-library method (`CURRENT-STATE-OF-PROJECT.md`),
which defines what trika-x uses but never defined:

- **T — Textual.** The text says it (exact identity). Usage here: root-text
  quotation, VERIFIED-QUOTE entries, decided Lean encodings of stated rows.
- **R — Reconstructed.** Argued from texts (gold argmaps, models, preregs).
  R never promotes itself — upgrade needs verbatim binds + review (CRUX-03
  is the standing example: T→R correction by its own gate).
- **E — Empirical.** Observed (diaries, pilots, measurements, decoder stats).
  Single-diarist/small-n stays pilot-labeled; descriptive, never verdicts.
- **C — Correspondence.** Cross-source resonance (IPK↔Ratié↔Solms convergence,
  structural parallels). Suggestive, never proof; flattening forbidden
  (the camatkāra tension is the standing example).
- **H — Hypothesis.** Stated guess with kill conditions. Lives in preregs
  and open questions, never in conclusions.
- **X — Rejected.** Killed with reason and date (twins that refuse, failed
  replications, falsified models). Kept as lineage, never deleted.
